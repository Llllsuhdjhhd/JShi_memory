# 历史文档归档

本目录保存本次文档重整前仓库中已跟踪的 Markdown 文件。文件内容按原文迁移，没有删除；原相对目录结构保留在 `history/` 下，便于查找和比较。历史文档不保证与当前实现一致，不作为现行行为说明。文档中的相对路径仍按搬迁前位置书写，可能无法在新位置解析。

新的当前文档从仓库根目录 `README.md` 和 `docs/` 下的模块文档进入。发现历史设计仍有价值时，先对照源代码，确认仍适用后再把结论改写到对应模块文档。

归档包含原根目录、`design/`、`docs/`、`my_idea/` 和 `tests/` 下的 Markdown 文档。迁移仅针对 Git 已跟踪的文档；未跟踪的本地文件和个人工作材料保留在原处。
