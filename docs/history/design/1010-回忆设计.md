# 1010 回忆设计

> 范围：1010–1209（子文档可用 1020–1200）｜状态：当前方案

回忆把记忆材料交给认知系统。它不针对线索写答案，也不解释、不反思、不收成新知识。

这一版材料只有两种：事件、对象事件事实。肖像、关系、图以后再加，不进这一版。

情绪已经写进遗忘因子。它不作为一条结果，也不单独检索。

## 1. 材料

材料用封存时写好的表示。回忆时不再摘要，不再改写。

### 1.1 事件

材料是该事件的 `summaries`。L1 信息最多，后一级只压缩前一级。原文 `content_raw` 不是一级表示。

### 1.2 对象事件事实

材料是某个对象在某一条事件上的 `fact`。同样 L1 最长，后一级更短。它现在存在白描条目里：正文为 L1，更短的级在既有三列。它不是肖像。

### 1.3 尚未封存的句子

未封存句子可以按词面交回，种类标成尚未封存。这不是第三种材料。

## 2. 范围

指定了对象时，候选只有两块：该对象自己的事实，以及 `role_list` 含有该对象的事件。不从一条事实反推所属事件，再把该事件里其他对象的事实一并召回。

指定了时间范围时，按事件的 `occurred_at` 过滤。未给出的条件不做猜测。「上次」「去年」留在原始线索里，交给语义和词面，不由模型改写成另一句问题。

未传对象时，单个 `object_id` 仍然有效。

## 3. 检索

四路是手段，不是四种记忆。

```text
线索
 ├─ 语义：事件 L1、对象事实 L1 的向量
 ├─ 词面：人名、专名、数字、短语，对这两类文本做子串和词面匹配
 ├─ 对象：调用方传入的对象，硬限制
 └─ 时间：调用方传入的时间范围，硬过滤
```

每一条候选保留原始信号。对象指定时，按对象与本轮输入的关系加权排序。0.7 的角色判定依赖写入时保留的历史对话对象 ID；`role_list` 只说明事件涉及哪些对象：

- `semantic`
- `lexical`
- `object`：命中为 1，否则为 0
- `temporal`：落在范围内为 1；未给时间范围则不填
- `object_role_weight`：本轮对话对象也出现在该事件的历史对话对象来源段中时为 0.7；仅作为涉及对象命中时为 0.3；未指定对象时为 1.0

用于排序的分数为 `max(semantic, lexical) × object_role_weight`。命中门槛仍使用未加权的语义或词面分，避免 0.3 权重把其他对象的有效线索挡在候选集外。对象事实按所属对象是否有历史对话对象归属加权；未闭环候选按已保存的历史对话对象归属加权。结果的 `score` 是加权排序分，`signals` 保留原始语义分、词面分和对象角色权重。

历史对话对象按来源经历段保存；一个事件包含多个段时可返回多个对象及段 ID。旧事件没有这项来源数据时，历史对话对象为空，系统不从 `role_list` 推断谁曾是对话对象。

对外结果带原始信号、对象角色权重和最终排序分，便于检查排序依据。

进入候选的条件：语义或词面达到门槛即可。门槛是配置，不写进本文。对象和时间只在调用方传入时才限制集合。

封存时为对象事实的 L1 单独写一条向量，载荷标明种类。事件 L1 仍单独一条。两条向量进入同一个语义空间：同一个嵌入模型、同一套距离。

### 3.1 向量只索引 L1

向量文本就是这一级表示本身。没有 L1 时不为这条材料建向量，也不改用原文。对象编号、种类标签不写进向量文本，记在载荷里。载荷至少包括：种类、事件编号、对象编号、主体、表示级别、L1 的哈希、嵌入模型和嵌入版本、发生时间。

库里的表示是正文来源。向量只提供语义分数。

同一条材料的 L1 哈希和嵌入版本都没变时，再次索引不重新嵌入。L1 变了，或嵌入版本变了，才重新嵌入。换嵌入模型使用新集合，不覆盖旧集合。

语义检索在已经给出的主体、对象和时间范围内取前若干条。对象和时间仍是硬限制。

## 4. 排序与可及性

排序先看加权相关度。原始相关度取语义和词面的较大值，词面精确命中（专名、数字）可达到 1；对象角色权重再作用于该分数。

可及性是遗忘因子，并随时间衰减。它不得改变明显不同加权分之间的顺序。语义很高、可及性极低的条目，仍排在加权分明显更低、可及性极高的条目前面。只有加权分接近时，可及性才决定谁先被想起。接近的幅度是配置，不写进本文。

可及性不把强线索挡在门外。已经沉下去的条目，若这次线索确实命中，仍然进入候选。

## 5. 预算与交回

总预算是整次回忆的字数，不是每一条都返回 L1。未传预算时，用现有的默认预算。

预算控制的是选用哪一级完整表示，不把表示或原文截成半截。对一条材料，选取放得进预算且信息最多的一级。例如 L1 900 字、L2 430 字、L3 210 字：预算 250 用 L3，500 用 L2，1000 用 L1。预算短于最短一级时，不返回该材料，也不返回截断的原文。原文只在调用方明确要求展开、且全文放得进预算时才交回。

对象线索先放该对象的事实；预算还有余，再附上所属事件的摘要。同一事件可以同时出现为事件和对象事实，种类不同，不去重。同一种类、同一编号只留一条。

每条结果带：

- `type`：`event`、`object_event_fact` 或 `unclosed`
- `event_id`
- 可选 `object_id`
- `representation_level`
- `content`
- `signals`

不再把情绪或重要性放进结果。

## 6. 命中之后

命中之后加强遗忘因子，把这条重新标成可及。不改原文，不补写后来发生了什么。

## 7. 这一版不做

- 肖像的生成和召回，关系和图。
- 用模型改写线索。
- 模型精排。
- 把回忆写成回答。
- 按高兴、失望再开一路检索。
- 不拆事件，不改摘要，不给对象补一句新事实。
- 不把一次命中收成长期认识。那是以后的巩固。

## 8. 预留

关系、肖像等以后可以各加一种材料、一种结果种类。现在不建，也不在这次交回里推断谁和谁是什么长期关系。结果里带对象编号，供以后使用。

## 9. 与其他部分的关系

- 写入负责形成事件、摘要、对象事实和遗忘因子。回忆只读这些结果，命中后只加强遗忘因子。
- 对象事实的长短各级在封存时写好。回忆按预算选用，不在召回时重新压缩。
- 巩固、做梦不在本部分。
