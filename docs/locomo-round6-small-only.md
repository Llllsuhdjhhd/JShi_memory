# 取消全部到龄聚合：197 与 179 个小事件同题测试

按用户要求，本次测试不做三个月聚合，也不做任何其他年龄阶段的聚合。结果显示，不聚合时两份小事件库的成绩接近；不能再把此前 V3 下降简单解释成 179 个小事件不如 197 个。

## 结果

同一历史、同一 30 题及冻结答案条目，同一真实 JShi 核心、deepseek-flash、英文 BGE、L0 索引和材料预算。原时间标签及提问时刻保持不变。

| 指标 | V2 原聚合版 | V2 仅197个小事件 | V3 原聚合版 | V3 仅179个小事件 |
|---|---:|---:|---:|---:|
| 自动答对 | 15/30 | 16/30 | 11/30 | 17/30 |
| 阅读复核后答对 | 16/30 | **17/30** | 11/30 | **18/30** |
| 可回答题答对，复核后 | 11/24 | **13/24** | 7/24 | **13/24** |
| 对抗题答对 | 5/6 | 4/6 | 4/6 | 5/6 |
| 自动充分信息覆盖 | 54.17% | 64.58% | 43.75% | 68.75% |
| 复核后充分信息覆盖 | 54.17% | **68.75%** | 39.58% | **68.75%** |
| 复核后完整覆盖题目 | 50.00% | **66.67%** | 37.50% | **66.67%** |
| 官方 F1，保持原答案 | 29.53% | 26.08% | 21.96% | 35.36% |

充分信息覆盖是对 24 道可回答题分别计算条目覆盖后取均值，不是所有条目的微平均。完整覆盖 66.67% 即其中 16/24 题。

两份不聚合记忆库，可回答题正确数和充分信息覆盖相同。整体 17 与 18 的一题差来自对抗题正确数不同；但具体答对的题并不完全一致。197 条库独有正确题为 q1、q29、q64；179 条库独有正确题为 q162、q27、q37、q116。因此不能说两库逐题等价，也不能仅凭单轮认定一个版本稳定胜出。

V2 官方 F1 下降而语义正确数增加，体现答案措辞及对抗题表现对词面指标的影响；本次没有改写核心答案来提高 F1。

## 怎么取消聚合，避免重新切分干扰

没有重新输入 419 条对话，也没有重新调用模型提取小事件。

- 从 V2 保存的底层记录恢复全部 197 个原小事件，包括之前被隐藏的 95 个。
- 从 V3 恢复全部 179 个原小事件，包括之前被隐藏的 83 个。
- 为两组各建一个干净的测试库，只存原小事件，排除各自 28 个上层事件及聚合产生的对象事实等附属记录。
- 仅清空底层的上层隐藏链接、恢复未被聚合标志；原事件 ID、正文、来源、时间及其他原字段通过校验保持一致。
- 重建小事件原文向量索引；所有小事件可被检索，实际每题仍由检索选择交付材料，不是把全部事件一次性塞给核心。
- 不执行后台提炼，默认正式运行的年龄配置没有改动。

两份原始数据库均按只读方式访问，并核对前后文件哈希。197 条库原有的 4 组包含式重复保留，179 条库仍为 0 组；不额外清洗原始事件，避免同时改变另一个条件。

结构审计确认两组分别为 197/179 条阶段 0 事件，全部可见，隐藏数 0，上层事件数 0；都覆盖 419 个原发言来源，30 题回忆轨迹没有结构违规。

## 日期评分复核

自动评分和人工意义上的真实正确并不完全一致，本次保留全部原始评分，另存代理阅读复核：

- 197 条库 q1：模型回答“去年”，在 2023 年评估时刻及 2023 年原始来源下均指 2022。裁判也承认能推出 2022，却因未拼写年份及多了 lake 一词判错。按既有语义等价口径改为正确，覆盖改为可推导。
- 179 条库 q16：“昨天，记忆日期为 2023-07-03”明确等价于 7 月 2 日。裁判对同一等价关系在另一组判对、本组判错，故复核改为正确。
- 两组 q28、q29、q33 的覆盖分类由直接改成可推导：绝对日期需要来源日期与相对词共同确定，不改变其充分覆盖；最终回答判定不因此改动。

未将无日期锚点的“上周五”改成正确；没有把原始库里有答案当成交付成功，也没有因 q184 的选项协议问题调整正式成绩。详见各组 `reading_review.json`、独立的 `reviewed_grades/` 和 `reviewed_summary.json`，含修改前后内容及哈希。

## 判断与局限

此次结果支持用户的疑问：此前巨大落差有明确的聚合信息损失证据，并不是减少 18 个事件就必然损失那么多能力。V3 取消聚合后，复核正确数从 11 增至 18，其中可回答题从 7 增至 13，藏书、会议见闻、报名事件等细节重新进入实际回忆。

但尚不能将所有分差都归因于聚合：回答和评分重新调用模型，仍有随机性；对抗题及日期判定也会变动。当前是同批开发题的一轮对照，不是多次重复的显著性检验。对原始小事件正文、隐藏恢复及上层排除有严格校验，对具体分数只作本轮结论。

后续应先以“不聚合的小事件库”作为排查检索和回答的基线，再修聚合中的来源覆盖与事实预算分配。不能只用总体分数判断压缩是否保真。
