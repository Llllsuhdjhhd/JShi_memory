## 文档与代码的优先级

1. 运行中的源代码决定当前实际行为。
2. 单元测试和跨仓契约测试记录已验证的行为边界。
3. 本目录解释代码行为，并指出接口占位和已知缺口。
4. `docs/history/` 只用于追溯。历史设计不能单独证明某个功能已经实现。

更新代码后，应同步更新对应模块文档和验证说明。发现文档与代码不一致时，先修正文档；如果确实要改变行为，再另开草稿记录目标和实施方案。

## 文档范围约定

- 项目总览只说明组件关系，不复制详细 API 字段。
- 记忆文档说明写入、事件生命周期和持久化。
- 回忆文档说明实际检索路径及概率行为；参数默认值以代码配置为准。
- 匠石交互文档说明两侧端口和字段映射，不把查询对象误写成历史说话人。
- 草稿箱是过程材料；已完成方案要把稳定结论同步到模块文档。
