## 五、结论与遗留

**结论**

1. 记忆落位质量整体合格：新事件摘要/白描/情绪与原文一致，无幻觉；被否事件情绪（sadness 0.6、valence −0.14）与内容吻合。
2. 回忆质量受"数据污染"影响远大于算法：清除强化污染后 Recall@1 提升 5 倍，验证了测量纪律（只读）的必要性。
3. 对象路对多对象事件有效（"陈姐方案被否"、"杭州阿明" R@1 命中）。

**遗留问题**

- 旧事件 l1/l2/l3 白描为空（历史数据，不回溯）。
- EVT-22e723 幽灵对象白描（修复前污染，可选用 tombstone/清理脚本处理）。
- 低唤醒规则记忆（act 0.3）排序吃亏："arousal 当强度、无等级"设计约束下的固有 trade-off。
- L1 可检索性提示词改动已生效于后续 ingest，需真实对话闭环后复测。
- qdrant-client 本地模式 delete+recreate 同名 collection 维度切换有缓存 bug（已记录，换维度需删目录重建）。
