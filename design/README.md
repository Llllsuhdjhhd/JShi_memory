# 匠石记忆后端（Jshi_memory）设计文档库

本目录是本仓库（REMS3 fork）改造的设计文档库：**先写清每一部分要改什么、为什么改、目标是什么、与哪些模块相关、预留什么、有哪些待讨论点，确认后再动代码。**

## 编号规则

- 每部分从 10 开始，间隔 200：`10, 210, 410, 610, 810, ...`
- 编号为 N 的部分，其全部内容（含子文档）写在 `[N, N+200)` 区间内
- 子文档使用区间内的中间编号，例如 10 部分的子文档可用 `20, 30, ..., 200`
- 每部分一个主文档，文件名格式：`<编号>-<名称>.md`

## 每部分文档模板

每部分主文档必须包含以下小节（未定项写"待讨论"）：

1. **改动内容** —— 具体改哪些代码 / 数据 / 接口
2. **原因** —— 为什么必须改（对应哪条需求约束）
3. **目标** —— 改完后的可验证结果
4. **与其他模块的关系** —— 上下游依赖、影响面
5. **预留的功能** —— 本次不做但需保留的接口 / 数据结构 / 扩展点
6. **待讨论问题** —— 需要拍板的点
7. **验收标准** —— 跑哪些测试、达到什么结果
