# 410 对象时间线（角色系统改造）

> 范围：410–609（子文档可用 420–600）｜状态：已确认（定稿）

## 1. 改动内容

### 1.1 现状（要改掉的）

- 角色由 LLM 抽取：RoleExtractionSkill 两阶段，`role_id` 内部生成（`ROL-<uuid>`），维护名字 / 别名；
- 白描时间线每角色含 `role_summary` + `emotional_model` + 遗忘因子（**对象级情感**）；
- 无主体概念：UserMode SINGLE / MULTI、`core_user_role_id`、`active_participants` 做代词消解。

### 1.2 目标模型（对齐契约 + 情感只属主体）

- **不建角色系统**：对象一律用 01 的 `object_id`；记忆侧**不抽取、不建档、不创建角色**；
- **对象映射表**：输入 `objects`（名字 / 称呼 → 01 object_id，含没说话的、未在文本中出现的）→ 后端据此把 `object_ids` 挂到记忆单元，`role_id` = 01 `object_id`（防重名）；对象归属以映射表为准，不要求文字提及；**呈现时名字与 id 并存**（与输入映射表一致，便于阅读，如回忆时）；
- **白描保留（white_painting_entries，匠石视角）**：每个对象维护匠石对该对象的**分级白描**（`l1_mention` / `l2_interaction` / `l3_decision`），**事件关联**（`event_id`，白描 ↔ 事件关系可追溯）；对象**无情感、无等级**；
- **对象记忆时间线（ObjectMemoryEntry）**：`object_id` + `name`（呈现用）→ 该对象在一事件中的一句摘要快照 + 时间，按时间组织；**无情感字段**（已定：情感只与匠石相关，与对象无关）；表保留、记忆路径不再写入（白描由 white_painting_entries 承担）；
- **主体恒在（类人记忆效果）**：记忆以主体（匠石）为中心；事件角色列表恒含主体，对象按映射表挂载；未在文本出现的主体 / 对象不丢归属；
- **主体记忆合法**：`objects` 为空 → 角色列表可只含主体；
- **情感只属主体（事件级）**：事件携带匠石的情感（8 维 + arousal / valence / energy），由 state 类内容提取；对象不携带情感；**情感（arousal）影响遗忘因子**（初始化抗遗忘强度，随时间衰减）；
- **遗忘 / 静默**：以记忆单元级 `memory_status`（sealed / suppressed，只降可见性、不删原文）为主；对象时间线不做遗忘因子（仅摘要轨迹，待讨论 3）。

### 1.3 涉及代码

- `models`：对象时间线条目（object_id + name + 一句摘要 + 时间）；移除情感字段；
- `services`：对象时间线服务——按输入 `objects` 挂载 `object_ids`、封存后追加条目；EMAEvolver 作用于主体情感（事件级滚动）；
- `skills/role_extraction.py`：删除（清单 1410）；
- `storage/repository.py`：按 01 object_id 读写时间线条目；
- `config.py`：删除 `user_mode` / `core_user_role_id` / `active_participants`；
- 回忆侧引用对象数据的代码**不动**（1010）。

## 2. 原因

1. **契约**：对象来自 01，不抽取、不建档、不建角色系统；
2. **情感只属主体（已定）**：情感只与匠石有关，对象 / 角色不携带情感；
3. **主体恒在（类人记忆效果）**：记忆以主体为中心，文字缺省不丢归属；
4. **role_id 稳定性**：`role_id` = 01 object_id，保证长期稳定，与 01 体系一致。

## 3. 目标

- 对象时间线 = 摘要快照轨迹（object_id + name + 一句摘要 + 时间），无情感；
- 主体情感单独维护（8 维情绪 + EMA 演化）；
- 删除 LLM 角色抽取与对象级情感；
- 对象相关 `tests/unit` 按新模型调整并全绿，其余基线不回归。

## 5. 预留的功能

- 对象档案：01 后续推送结构化对象内容 → 记忆侧档案字段（输入仍只带映射表）；
- 未知名字候选：契约允许"返回候选"，形态待定（见待讨论 2）；
- 多主体：`subject_id` 参数化（当前恒单主体）；
- 回忆侧对象焦点（`object_id` 过滤）数据形状保持兼容。

## 6. 定稿决策（2026-08-23 确认）

1. **role_id**：直接 = 01 `object_id`（防重名，主键稳定）；**呈现时 name + object_id 并存**（与输入映射表一致，便于阅读，如回忆时）；
2. **未知名字**：保持原样，不返回候选、不自行解析；
3. **对象时间线字段**：object_id + name + 一句摘要 + 时间；无情感；**无 importance**（回忆启用时可扩展）；
4. **主体情感**：事件级，**事件顶层 emotion 字段（已定）**；EMA 滚动由事件历史推导；
5. **代词消解**：无主语 / 第一人称动作默认归主体（匠石），在 610 提示词落地。
