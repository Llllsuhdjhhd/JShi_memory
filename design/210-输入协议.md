# 210 输入协议

> 范围：210–409（子文档可用 220–400）｜状态：已确认（定稿，对齐匠石《记忆层契约》）

## 1. 定位

- 本后端（REMS3 fork）实现匠石 `MemoryBackendPort`；主流程只依赖端口形状，不绑定引擎；
- 硬约束：**无抽象事件**；**不建角色系统**（对象一律用 01 的 `object_id`）；只做记忆；原文保全；
- 权威接口以匠石《记忆层契约》为准，本文件是其实现说明与改造范围。

## 2. 写入契约（记忆 ingest）

```python
class MemoryInput:
    subject_id: str                     # 归属匠石，恒在
    text: str                           # 经历原文（含名字；多轮可整段进入）
    objects: dict[str, str] = {}        # 对象映射表：名字/称呼 → 01 object_id（含没说话的）
    source_ids: tuple[str, ...] = ()    # 来源链：事实 / 活动 / 认知 id，必带
    occurred_at: datetime | None = None
    input_id: str | None = None         # 30 侧经历段 id，用于 stored_marks 回填
    origin: str = "external"            # external | internal | dream


class MemoryBatch:
    subject_id: str
    inputs: tuple[MemoryInput, ...]     # 有序：对话 / 经历先后顺序


class BackendIngestResult:
    subject_id: str
    stored_marks: dict[str, list[str]]  # input_id -> 本轮封存事件 id 列表（封存几个填几个；契约草稿为单值，建议修订为列表）
    sealed_event_ids: list[str]
    role_ids: list[str] = []            # 本轮登记 / 更新的 01 对象，可为空
    unclosed_count: int = 0
    errors: list[str] = []              # 非致命错误
```

约定：

- `text` 是原文，**不归一化、不改写、不切分**——"不切分"指输入层：JShi 侧不按回合拆分，整段经历作为一个 `MemoryInput` 进入；后端内部代谢切分是内部流程，与输入无关，**内部切分流程保持不变**（边界检测、未完成 / 残影等 REMS3 机制照旧，见 610）；
- `stored_marks`：一个 input 封存几个事件就填几个（`input_id → 事件 id 列表`）；本轮未封存任何事件（全部留在未完成缓冲）则不写该项，不算错误（→ 610）；
- `objects` 覆盖一段经历涉及的对象，**与是否说话、是否在文本中出现都无关**（记忆效果类比人类：以主体为中心，对象归属以映射表为准）；可为空（= 主体记忆）；
- `source_ids` 必带，保证来源可追溯；
- 30 构造 `MemoryInput` 时按经历段映射：`text_raw → text`、`objects → objects`、`source_ids → source_ids`、`input_id = segment_id`、`origin` 按 `output_kind`（`external_input` / `subject_reply` / `subject_state` / `subject_silent` → `external`；`internal` → `internal`）。

## 3. 读取契约（回忆 recall，预留）

```python
recall(
    subject_id: str,
    query: str,
    *,
    object_id: str | None = None,
    level: int = 1,
    limit: int | None = None,
    anchor_event_ids: tuple[str, ...] = (),
) -> tuple[RecalledFragment, ...]
```

- `RecalledFragment` 至少含：`event_id`、`text`（原文）、`kind`、`object_id`、`source_ids`、`score`、`summary_level`；
- 查询保持原文；对象过滤用 `object_id`（可空 = 跨对象，含主体记忆）；
- 契约"回忆只读"理解为：**不新增记忆单元、不登记 recall_log**（无抽象，recall_log 不用）；**记忆恢复保留**——被召回的记忆强化遗忘因子（回忆加强记忆，符合常理，REMS3 机制照旧 → 1010）。

## 4. 端口（四步）

```text
MemoryBackendPort:
  ingest_batch(batch: MemoryBatch) -> BackendIngestResult   # 本轮实现
  recall(...) -> tuple[RecalledFragment, ...]               # 占位不动
  consolidate(subject_id, *, budget=None, cursor=None)      # 占位
  dream(subject_id, *, object_id=None, budget=None)         # 占位
```

## 5. 记忆单元（后端内部）

| 字段 | 说明 |
|------|------|
| `memory_event_id` | 记忆单元稳定标识 |
| `subject_id` | 归属匠石，恒在 |
| `object_ids` | 01 对象标识集合（来自输入映射表，可为空 = 主体记忆） |
| `content_raw` | **原文**（含名字；不归一化、不改写） |
| `summaries` | 先 L1 单层，稳定后再扩展 |
| `source_ids` | 来源链 |
| `activity_id` | 活动锚点（可选） |
| `occurred_at` | 发生时间 |
| `memory_status` | sealed / suppressed（遗忘只降可见性，不删原文） |
| `emotion` | 事件级主体情感（匠石在事件中的 8 维情绪 + arousal / valence / energy）；**对象无情感**；情感（arousal）影响遗忘因子（实现扩展，契约未列） |

- **对象记忆时间线（ObjectMemoryEntry）**：`object_id` → 该对象在一事件中的一句摘要快照，按时间组织（≈ REMS3 白描条目，详见 410）；
- 后端内部代谢可把一段输入切分为多个记忆单元；每个 `content_raw` 均为原文的忠实片段，永不改写（"原文保全"是不变量，`content_raw == 输入 text` 在单单元场景下成立）；
- **未完成事件 / 残影**：后端内部工作缓冲，不跨端口暴露。

## 6. 后端必须遵守

1. **原文保全**：`content_raw` 永不改写；
2. **对象来自 01**：不抽取、不建档、不建角色系统；文本中出现未知名字时保持原样或返回候选，不自行解析；
3. **无抽象事件**：不做频繁子集挖掘、ASF、`source_events`、抽象合成；
4. **主体恒在（类人记忆效果）**：记忆以主体（匠石）为中心；即使 text 未提及主体或对象，事件角色列表恒含主体，对象以映射表为准、不要求文字提及；`objects` 可为空（主体记忆），角色列表可只含主体；
5. **记忆 / 回忆独立**：`ingest_batch` 与 `recall` 互不耦合；`consolidate` / `dream` 为后台接口（本轮占位）；
6. **失败隔离**：单次 ingest / recall 失败不污染历史、承诺或个人世界；
7. **可替换**：与 JShi 的 `InProcessMemoryBackend` 实现同一端口形状，替换后主流程行为不变。

## 9. 定稿决策（2026-08-23 确认）

1. **输入层不切分、内部切分保持不变**；`stored_marks` = `input_id → 本轮封存事件 id 列表`（封存几个填几个；完全未封存不写该项、不算错误）；
2. **摘要**：保留 L1–L10 多级衰减（至少 L1 对外可用）；
3. **source_ids**：可多值（tuple）、必带；缺失时该 input 进 `errors`、不封存（来源不可追溯，违反契约）；
4. **occurred_at**：落库（经历时间），`create_time` 保留（摄入时间）；
5. **memory_status**：sealed = active、suppressed = silent、unclosed 仅缓冲（810 定稿）；
6. **未知名字**：保持原样，不返回候选（410 定稿）；
7. **recall**：不新增记录、不登记 recall_log，保留记忆恢复（被召回记忆强化遗忘因子）。
